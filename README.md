# Simar Bhatia - Personal Portfolio Website

An interactive personal portfolio website inspired by [Adham Dannaway](https://www.adhamdannaway.com/), featuring a dual-personality split slider showcasing work as both a **Product Designer (UI/UX)** and a **Frontend Developer (<coder>)**.

---

## ✨ Features

- **Interactive Split-Slider Avatar**:
  - Center 50/50 split face.
  - Hover or drag left towards **Designer** to reveal the full creative UI/UX designer persona (vibrant colors, Figma, design systems).
  - Hover or drag right towards **Coder** to reveal the clean frontend developer persona (tech glasses, dark theme, glowing code elements).
- **Dual Interaction Modes**:
  - Dynamic cursor/hover tracking across the hero wings.
  - Custom draggable handle (`◀ ⚡ ▶`) with touch support on mobile.
  - Quick-snap buttons to instantly glide to Designer, Coder, or 50/50 view.
- **Modern Minimalist Header**:
  - Monogram brand logo (`SB`).
  - Social media integrations (GitHub, LinkedIn).
  - One-click copy email button with feedback tooltip.
- **Pure & Lightweight**:
  - Zero heavy framework dependencies.
  - 60fps smooth animations with hardware acceleration.
  - Fully responsive across desktop, tablet, and mobile devices.

## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/simarbhatia2004/simar-portfolio.git
   cd simar-portfolio
   ```

2. **Run the local server**:
   ```bash
   node server.js
   ```
   Or open `index.html` directly in any modern web browser.

3. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).

---

## 🎨 Customizing Avatars

To replace the animated avatars with your own photographs, simply place your photos into `assets/images/`:
- `avatar-designer.jpg` - Your designer persona image.
- `avatar-coder.jpg` - Your coder persona image.
- `avatar-split.jpg` - Optional 50/50 split image.
